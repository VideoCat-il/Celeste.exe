# ⚠️ ADVERTENCIA IMPORTANTE

Este es un **proyecto educativo/artístico** que demuestra:
- Cómo crear bucles infinitos en Godot
- Consumo descontrolado de recursos
- Bloqueo de cierre de ventanas

**SOLO EJECUTAR EN:**
- Máquina virtual (VirtualBox, VMware, Hyper-V)
- Con RAM limitada (2-4GB máximo)
- En tu propio sistema

**NO EJECUTAR EN:**
- Tu PC principal
- Sistemas de producción
- Sistemas ajenos

Este proyecto es con fines educativos únicamente.
**De que va el virus**

El virus va del videojuego celeste, donde aparece Madeline bloqueando el uso del pc, mandándote fresas sin parar hasta petar la ram
